# Assignment #4 — Forms and Validation

A responsive multi-page website demonstrating HTML forms, HTML5 validation, Bootstrap form styling, validation feedback classes, and a registration form.

## Technologies
- HTML5
- CSS3
- Bootstrap 5.3

## Pages
- `index.html` — Home page and navigation
- `task0.html` — Simple contact form
- `task1.html` — Contact form with HTML5 validation
- `task2.html` — Bootstrap form styling and responsive grid
- `task3.html` — Bootstrap `is-valid` / `is-invalid` feedback examples
- `task4.html` — Registration form with password length, radio buttons, checkboxes, country dropdown, submit and reset buttons

## Run locally
Open `index.html` in a web browser. Bootstrap is loaded from the CDN, so an internet connection is needed for Bootstrap styling.

## Publish with GitHub Pages
1. Create a GitHub repository and upload all files, keeping the `css` folder.
2. Open **Settings → Pages**.
3. Under Build and deployment, choose **Deploy from a branch**.
4. Select the `main` branch and `/ (root)` folder, then save.
5. After publishing, open the Pages URL shown in repository settings.

## Notes
HTML5 validation works in the browser. Task 3 shows Bootstrap feedback classes as static examples because JavaScript is intentionally not used. Matching the password and confirmation fields automatically requires JavaScript or server-side validation.
